# DeliveryPro — Delivery Executive User Panel (Phase 1)

A modern, mobile-first **Delivery Executive Performance & Information Portal** built for delivery executives to track performance metrics, orders history, earnings, milestone incentives, leaderboard rankings, rewards, referrals, and support tickets from smartphones and desktop browsers.

---

## 📱 Features

- **Mobile-First UX**: Specifically engineered for 390×844px and common smartphone viewports with bottom navigation, gesture drawers, and 44px+ touch targets.
- **Authentication**: Simulated OTP login (+91 mobile number validation, 6-digit auto-advancing code boxes, 30s resend timer).
- **Performance Dashboard**: Executive KPIs (Orders, Earnings, Bonus, Rank), active KYC and account status pills, and weekly overview.
- **Milestone Progress**: 4-tier milestone ladder (Bronze, Silver, Gold, Platinum) with visual percentage progress bars and unlockable bonuses.
- **Orders History**: Filter orders by *All*, *Completed*, *Cancelled*, and *Under Review* with interactive bottom sheet details.
- **Earnings & Payouts**: Recharts interactive graph, period switcher (Today, This Week, This Month, Custom), daily breakdown ledger, and bank transfer records.
- **Weekly Contest & Leaderboard**: Weekly Delivery Champion prize pool podium (1st, 2nd, 3rd) and real-time rankings with current user highlighted (#12).
- **Rewards & Merchandise**: Unlocked cash reward claims with celebratory animations and official merchandise status tracking.
- **Referral Program**: Unique referral code (`DROPY123`), 1-tap WhatsApp/Telegram sharing, and invite funnel tracking.
- **Financial Services**: Personal loan eligibility calculator modal, partner RuPay credit card offers, and prepaid company card wallet balance.
- **Support Desk**: Raise complaint form with category tagging and real-time support discussion thread.
- **State Resilience Switcher**: Floating previewer to toggle between Live Data, Skeleton Loading, Empty States, and Error Fallback UI.

---

## 🛠️ Tech Stack

- **Framework**: React (v18) + Vite
- **Styling**: Tailwind CSS + Vanilla CSS utilities
- **Routing**: React Router DOM (v6)
- **Icons**: Lucide React
- **Data Visualization**: Recharts
- **Animations & Micro-interactions**: Framer Motion
- **Forms & Validation**: React Hook Form
- **Celebrations**: Canvas Confetti

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/rahuldropyhub-wq/delivery-management.git
cd delivery-management
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
```
